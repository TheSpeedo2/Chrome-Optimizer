## Features

Chrome Optimizer is a lightweight, open-source tool designed to improve Chrome performance, reduce system resource usage, and simplify maintenance tasks. Key features include:

### 1. Chrome Installation
- **Version Selection:** Install Latest Stable, Beta, Dev, or Canary.
- **Optimized Installation:** Deploy Chrome with performance-oriented flags.
- **Update/Uninstall Options:** Easily update or uninstall Chrome from within the script.

### 2. Registry Tweaks
- **Privacy Enhancements:** Adjust Chrome and system registry for better privacy.
- **Performance Improvements:** Optimize network, CPU, and memory usage for faster browsing and search results.
- **Low Latency Settings:** Advanced TCP, DNS, and multimedia registry adjustments to reduce latency.

### 3. Launch Flags
- **Custom Startup Parameters:** Enable QUIC, GPU rasterization, parallel downloading, accelerated video decode/encode, and other performance-focused flags.
- **Renderer Optimization:** Configure Chrome processes for optimal resource usage.

### 4. Chrome Debloating
- **Service Removal:** Remove unnecessary Chrome services and background tasks.
- **Registry Cleanup:** Remove redundant or obsolete registry entries left by Chrome.

### 5. File and Cache Management
- **Unnecessary Files Removal:** Delete temp files and old Chrome data.
- **History and Cache Cleaning:** Clean browsing history, cookies, and cached data.
- **File Compression:** Reduce storage footprint for Chrome data.

### 6. Low Power and Data Saver Modes
- **Low Power Mode:** Optimized for systems with limited RAM (e.g., 4GB) to reduce CPU and memory load.
- **Data Saver Mode:** Minimizes network usage and background services for constrained connections.

## Usage

Run the script, follow the on-screen instructions, and select the tweaks or installation options you wish to apply. Chrome Optimizer automates system and browser optimization for faster, more responsive, and private Chrome usage.
